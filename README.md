# Sophia's Legacy Site

Build a single-page personal brand website for Sophia Stewart — author, speaker, 

creator — matching this exact design direction:

BRAND / STYLE

- Color palette: black background, warm gold/mustard accent (#C89B3C or similar), 

  white/cream text

- Typography: elegant serif for headlines (e.g. "Playfair Display"), clean 

  sans-serif for nav/body (e.g. "Montserrat" or "Lato")

- Photography: full-bleed portrait image on the right side of hero, warm 

  library/bookshelf background, moody dark lighting

- Overall feel: premium, editorial, authoritative — like a high-end author/speaker 

  personal brand site, NOT flashy or gimmicky

NAV BAR (top, sticky)

- Left: "SOPHIA STEWART" logo wordmark (gold), subtext "AUTHOR | SPEAKER | CREATOR"

- Right: HOME, ABOUT, MEDIA, BOOKS, NEWSLETTER, CONTACT (all caps, spaced out, 

  gold underline on active/hover)

HERO SECTION

- Large serif headline, 3 lines, last line in gold:

  "The Story / The Journey / The Legacy"

- Subhead: "Author. Creator. Visionary. Explore Sophia Stewart's remarkable 

  journey, her books, media appearances, and the legacy she continues to build."

- Two buttons: solid gold "LEARN MORE" + outlined gold "WATCH INTERVIEWS"

- Right half: full-height portrait photo bleeding to page edge

ICON ROW (below hero, dark background band)

5 columns, each with a circular icon + gold label + 1-line description:

1. AUTHOR — "Books that inspire, inform, and leave a lasting impact"

2. SPEAKER — "Engaging audiences with real stories and powerful insights"

3. MEDIA — "Interviews, podcasts, and features from around the world"

4. CREATOR — "A creative journey driven by passion, purpose, and vision"

5. STAY CONNECTED — "Join the newsletter for updates, news, and exclusive content"

QUOTE BAND (bottom, solid gold background, black text)

- Centered italic quote: "Every story has power. Every voice has purpose. 

  Every legacy begins with truth."

- Attribution: "— Sophia Stewart"

BELOW THE FOLD (add these sections, same visual system)

- BOOKS section: 3-card grid — The Third Eye, Mother of the Matrix, 

  The Matrix: Evolution — cover image, title, 1-line hook, gold "View Book" button

- ABOUT preview: short bio + "Read Full Story" link

- NEWSLETTER signup: email field + gold submit button

- Footer: nav links repeated, social icons, copyright line

TECHNICAL

- Single self-contained HTML file, inline CSS/JS, no external deps except 

  Google Fonts (Playfair Display + Montserrat)

- Fully responsive — stack hero image below text on mobile

- Fast, lightweight, no heavy animation libraries

- Use placeholder image paths for photos I'll swap in later

Build this as a complete, ready-to-preview HTML file in one pass.
